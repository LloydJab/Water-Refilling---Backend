Our system is a POS with admin managing capabilities. It consists of web app and a mobile app which is POS and Admin monitoring correspondingly. It manages orders of customers whether they are walk-in or delivery and stores their orders in the database. It also tracks inventory and automatically deducts every time a gallon is refilled. The admin can then tracks current orders, if there are still pending customers even they are not on site. They can also see history records and also manages inventory for adding or deducting items.
